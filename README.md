# 🌿 پلتفرم جامع آموزش ابتدایی و مراقبت کلاسی «جوانه» (نسخه ۱.۰)

> **شاهکار معماری آموزشی، یادگیری شخصی‌سازی شده و شبکه هم‌افزایی معلمان مدارس**

سامانه‌ی **«جوانه»** پلتفرم جامع آموزش ابتدایی (پایه‌های ۱ تا ۶) و ابزار کارآمد معلمان و مدیران است که با هدف کشف گلوگاه‌های شناختی درس ریاضی، تولید کتب تعاملی آفلاین، ایجاد انگیزش با لیگ مسابقات کلاسی و گردونه شانس، و پایش سلامتی عاطفی کودکان در شبکه‌ی محلی مدارس طراحی شده است.

---

## 🪝 ضرورت استفاده از پلتفرم (قلاب‌های جذاب)

- **۱. کشف و رفع هوشمند گلوگاه‌های ریاضی (پایه‌های ۱ تا ۶ صفحه به صفحه):**
  - شناسایی نقطه افت دانش‌آموز بر اساس شماره صفحه دقیق کتاب درسی.
  - ارائه تمرین‌های جبرانی کوتاه و هدفمند جهت رفع ریشه‌ای ضعف ریاضی بدون ایجاد استرس یا سرخوردگی.

- **۲. کتاب‌ساز تعاملی و آفلاین معلمان (ابزارک آفتاب):**
  - تولید کتب درسی و کتابچه‌های تمرین تعاملی دیجیتال تنها در ۴ گام ساده.
  - خروجی فایل HTML مستقل و بدون نیاز به اینترنت جهت توزیع مستقیم روی تبلت دانش‌آموزان.

- **۳. شبکه علمی و تالار گفت‌وگوی معلمان:**
  - فیلتر هوشمند گروه‌های کاری بر اساس «پایه تحصیلی» (۱ تا ۶) و «موضوع درسی».
  - امکان طرح پرسش و پاسخ تخصصی، اشتراک‌گذاری تجربیات تدریس و هم‌افزایی معلمان.

- **۴. بازی‌وارسازی، لیگ مسابقات و چرخه شانس پاداش:**
  - ایجاد رقابت سالم کلاسی و منطقه‌ای با امکان ساخت لیگ مدارس.
  - گردونه شانس پاداش‌دهی روزانه جهت تثبیت عادات مثبت آموزشی و زیستی.

- **۵. عملکرد ۱۰۰٪ مستقل و آفلاین (PWA کلاسی):**
  - اتصال مستقیم تبلت دانش‌آموزان به سرور لپ‌تاپ معلم از طریق وای‌فای هات‌اسپات محلی (بدون نیاز به اینترنت بین‌المللی).
  - نصب آسان روی صفحه اصلی تبلت (PWA) بدون نیاز به گوگل‌پلی یا کافه‌بازار.

- **۶. مراقبت عاطفی و حفظ ریتم زیستی:**
  - رادار ۱۰ ثانیه‌ای حال کلاسی برای معلم و قانون «گیاه هرگز نمی‌میرد» جهت جلوگیری از سوگ و احساس گناه در غیبت‌های ناخواسته.

## 🚀 راهنمای کامل نصب و راه‌اندازی گام‌به‌گام

پیش‌نیاز: نصب بودن Node.js (نسخه ۱۸ به بالا) روی لپ‌تاپ یا سرور معلم.

### گام ۱: دریافت پروژه و نصب وابستگی‌ها
ترمینال را در پوشه پروژه باز کنید و دستور زیر را اجرا نمایید:
```bash
npm install
```

### گام ۲: اجرای سرور محلی شبکه کلاس
برای اجرای سرور و دسترسی دستگاه‌های موجود در شبکه محلی، دستور زیر را وارد کنید:
```bash
npm run dev -- --host
```
*آدرس آی‌پی لپ‌تاپ معلم (مانند `http://192.168.1.50:3000`) در ترمینال نمایش داده می‌شود.*

### گام ۳: ایجاد هات‌اسپات وای‌فای (Wi-Fi Hotspot)
1. هات‌اسپات گوشی یا وای‌فای لپ‌تاپ معلم را روشن کنید (بدون نیاز به بسته داده یا اینترنت).
2. تبلت‌ها یا گوشی‌های دانش‌آموزان را به همین شبکه‌ی وای‌فای متصل کنید.
3. مرورگر تبلت دانش‌آموز را باز کرده و آدرس آی‌پی معلم را وارد کنید.

### گام ۴: نصب مستقیم اپلیکیشن روی تبلت دانش‌آموز (PWA)
1. در مرورگر Chrome یا Safari دانش‌آموز، گزینه **«افزودن به صفحه اصلی» (Add to Home Screen)** را انتخاب کنید.
2. آیکون «جوانه» روی صفحه اصلی تبلت اضافه می‌شود و به صورت آفلاین اجرا خواهد شد.

## 📖 راهنمای ساده استفاده بر اساس نقش‌ها

### 👩‍🏫 ۱. راهنمای معلم (Teacher Garden)
- **رادار ۱۰ ثانیه‌ای:** مشاهده حال عمومی، حضور غیاب و وضعیت عاطفی کل کلاس در ابتدای زنگ.
- **کتاب‌ساز تعاملی آفتاب:** ساخت کتابچه‌های درسی، افزودن سوالات چندگزینه‌ای و خروجی HTML.
- **گلوگاه‌شناس ریاضی:** انتخاب پایه تحصیلی (۱ تا ۶) و صفحه کتاب درسی برای ساخت تکلیف جبرانی.
- **دیکته‌گو:** پخش صوتی تلفظ هوشمند کلمات یا ضبط صدای معلم.
- **تالار گفت‌وگو:** تبادل تجربه با سایر معلمان بر اساس فیلتر پایه و درس.
- **لیگ و گردونه شانس:** تعریف مسابقات کلاسی و اهداء پاداش از گردونه شانس.

### 🏫 ۲. راهنمای مدیر مدرسه (School Principal)
- **پایش کلان:** مشاهده شاخص‌های کلی مشارکت کلاس‌ها و وضعیت سلامت روان بدون افشای نمره فردی.
- **مدیریت لایسنس:** صدور کارت‌های QR جهت فعال‌سازی حساب معلمان و کلاس‌های جدید.

### 🎒 ۳. راهنمای دانش‌آموز (Student Room)
- **اتاق جوانه:** رسیدگی به عادات روزانه (خواب، مسواک، مشق) برای رشد گیاه شخصی.
- **گردونه شانس و لیگ:** چرخاندن گردونه پاداش پس از انجام تکالیف و مشاهده جایگاه کلاسی.
- **کتاب‌خوان:** مطالعه کتابچه‌های تعاملی معلم و انجام تمرین‌های ریاضی.
