# سند معماری و مهندسی موتور وکتور و انیمیشن‌های ارگانیک «جوانه»
### راهنمای پیاده‌سازی سیستم گرافیک واکنشی، حالات چهره و قوانین فیزیک کشسانی (Juicy Game Art) در وب بدون وابستگی خارجی

---

## ۱. چرایی شکست مدل‌های زبانی در خروجی SVG و راهکار حل آن

مدل‌های زبانی به‌طور پیش‌فرض وقتی کلمه‌ی «گیاه وکتور» را می‌شنوند، کد زیر را تولید می‌کنند:
```xml
<!-- الگوی استاتیک، تخت و بی‌روح که باید از آن اجتناب شود -->
<svg viewBox="0 0 100 100">
  <rect x="40" y="60" width="20" height="40" fill="brown" />
  <circle cx="50" cy="40" r="25" fill="green" />
</svg>
```
این خروجی چند نقیصه‌ی بزرگ دارد:
1. **تخت بودن رنگ‌ها (Flat Shading):** هیچ نوری در صحنه تعریف نشده است.
2. **عدم انحنای ارگانیک:** استفاده از مستطیل به‌جای منحنی‌های Bezier درج دو (`Q`) و سه (`C`).
3. **نبود مرکز ثقل مشخص (Transform-Origin):** هنگام چرخش یا تغییر اندازه، آبجکت حول مرکز خودش یا گوشه‌ی صفحه می‌چرخد و ریشه‌ی گلدان کنده می‌شود.
4. **بی‌توجهی به روانشناسی چشم و لبخند کودکانه:** عدم رعایت مردمک دوقلو و گونه‌های برجسته.

### راهکار معماری جوانه:
تبدیل رندرینگ SVG به یک **خط لوله‌ی چندلایه‌ای مقید به حالت (State-Driven Multi-Layer Pipeline)** که در آن:
- ساقه فنری است.
- چشم‌ها پلک می‌زنند.
- برگ‌ها پریودهای زمانی نامتقارن برای نوسان دارند.
- نور محیطی و های‌لایت‌ها لایه‌ی مجزایی روی هندسه تشکیل می‌دهند.

## ۲. خط لوله‌ی لایه‌بندی صحنه (Scene Composition Hierarchy)

برای جلوگیری از تداخل انیمیشن‌ها و خراب شدن پرسپکتیو، رندر هر کاراکتر باید در نمای دوبعدی ارتوگرافیک طبق ترتیب زیر (از پشت به جلو) لایه‌بندی شود:

```
[Layer 0: Halo Glow]           هاله نور کروی پشت سر کاراکتر (شعاع بزرگ، شفافیت متغیر)
  │
[Layer 1: Contact Shadow]      سایه‌ی بیضی‌شکل نرم تماسی زیر گلدان با سطح زمین
  │
[Layer 2: Stem & Background]   ساقه‌ی مرکزی و برگ‌های پس‌زمینه (رنگ تیره‌تر برای عمق)
  │
[Layer 3: Plant Head & Eyes]   کره‌ی اصلی سر، های‌لایت حبابی، گونه‌ها، مردمک‌ها و دهان
  │
[Layer 4: Fore-Leaves & Flowers] برگ‌های پیش‌زمینه و گلبرگ‌های شکوفایی (در صورت وجود)
  │
[Layer 5: Pot Body & Details]  خاک گلدان، بدنه‌ی مخروطی، لبه‌ی برجسته و نقش‌های گلدان
  │
[Layer 6: Accessories & Friends] کلاه‌ها، پاپیون، کفشدوزک و پروانه
  │
[Layer 7: Ambient Particles]   ذرات شناور شبنم، گرد طلایی و کرم شب‌تاب
```

## ۳. فرمول‌های ریاضی و Bezier برای اجزای زنده

### ۳.۱. ساقه با انحنای دینامیک (Quadratic Bezier)
ساقه‌ی گیاه یک خط صاف نیست، بلکه یک منحنی بزیه درجه دو است که نقطه‌ی کنترل آن با وضعیت روحی (`mood`) تغییر مکان می‌دهد:

$$P(t) = (1-t)^2 P_0 + 2(1-t)t P_1 + t^2 P_2$$

- نقطه‌ی شروع $P_0$: همیشه درون خاک گلدان ثابت است $(60, 96)$.
- نقطه‌ی انتهایی $P_2$: مرکز اتصال سر گیاه $(X_{\text{head}}, Y_{\text{head}} + 10)$.
- نقطه‌ی کنترل $P_1$: تعیین‌کننده‌ی قوس و انعطاف‌پذیری ساقه:
  - در حالت شاداب: $P_1 = (57, \frac{96 + Y_{\text{head}}}{2})$ — شیب متقارن به سمت بالا.
  - در حالت دل‌تنگ: $P_1 = (55, \frac{96 + Y_{\text{head}}}{2})$ — شیب متمایل به چپ.
  - در حالت بی‌تاب: $P_1 = (51, \frac{96 + Y_{\text{head}}}{2})$ — شیب شدید و افتادگی گردن.

کد در SVG:
```xml
<path d="M60 96 Q57 65 60 42" stroke="#2F855A" stroke-width="6" stroke-linecap="round" fill="none" />
```

### ۳.۲. آناتومی چشم‌های کارتونی زنده (Double-Glint Eyes)
چشم کارتونی جذاب هرگز یک دایره‌ی ساده‌ی مشکی نیست. چشم زنده از سه عنصر سلسله‌مراتبی تشکیل شده است:
1. **صلبیه/مردمک پایه‌ای:** یک بیضی عمودی تیره (`rx=3.6`, `ry=4.5`, fill: `#1D2A44`).
2. **برق اصلی نور (Catchlight):** دایره‌ی سفید در بالا-چپ مردمک (`r=1.6`, fill: `#FFFFFF`).
3. **برق ثانویه‌ی بازتاب خاک (Ground Reflection):** دایره‌ی سفید بسیار ریز در پایین-راست (`r=0.8`, fill: `#FFFFFF`).

این ترکیب دو های‌لایت متقارن باعث ایجاد عمق کروی در مردمک می‌شود.

```xml
<!-- چشم چپ زنده -->
<ellipse cx="-7" cy="-2" rx="3.6" ry="4.5" fill="#1D2A44" />
<circle cx="-8" cy="-3.5" r="1.6" fill="#FFFFFF" />
<circle cx="-5.8" cy="-0.6" r="0.8" fill="#FFFFFF" />
```

### ۳.۳. لبخند سه‌بخشی (دهان با زبان دو رنگ)
لبخندهای خطی ساده، حس بازی‌های فلاش قدیمی را می‌دهند. لبخند شارپ کارتونی نیاز به یک کاسه‌ی توخالی تیره با زبان صورتی برآمده دارد:

```xml
<g transform="translate(0, 4.5)">
  <!-- فضای تاریک داخل دهان -->
  <path d="M-5 0 Q0 6.5 5 0 Z" fill="#D90429" />
  <!-- تکه زبان صورتی هلالی داخل دهان -->
  <path d="M-2 3.8 Q0 2 2 3.8 Z" fill="#FF8FA3" />
  <!-- خط لب فوقانی برای کادربندی تمیز -->
  <path d="M-5.5 0 Q0 7 5.5 0" stroke="#1D2A44" stroke-width="1.8" stroke-linecap="round" fill="none" />
</g>
```

## ۴. الگوریتم رنگ‌آمیزی شارپ و سایه‌روشن سه‌بعدی

برای عبور از رنگ‌های کسل‌کننده، هر بخش از بدن کاراکتر باید یک گرادیان سه‌بعدی شعاعی یا خطی به همراه لایه‌ی های‌لایت حبابی داشته باشد.

### ۴.۱. پالت رنگ‌های کوانتایزشده بر اساس احوالات
| حالت روحی | بدنه اصلی (Main) | لبه نوری (Light) | سایه عمقی (Dark) | لپ‌ها (Blush) |
| :--- | :--- | :--- | :--- | :--- |
| **شاداب (Thriving)** | `#48CA84` | `#95E3A8` | `#2B9348` | `#FF7B72` (گلگون) |
| **آرام (Content)** | `#5BB784` | `#A3DEBD` | `#3A8A5C` | `#FFA07A` (ملایم) |
| **دل‌تنگ (Longing)** | `#84C99D` | `#BFE7D0` | `#569C70` | شفاف (بی‌رنگ) |
| **بی‌تاب (Alert)** | `#A7CEB7` | `#D3EAE0` | `#799E89` | شفاف (پژمرده) |

### ۴.۲. های‌لایت حبابی سر (Bubble Specular Arc)
با افزودن یک کمان باز با `stroke-linecap="round"` روی سر، حجم سه‌بعدی شبیه به شخصیت‌های پیکسار بازسازی می‌شود:

```xml
<!-- های‌لایت کروی براق روی کله‌ی گیاه -->
<path
  d="M -11 -4 A 13 13 0 0 1 5 -12"
  stroke="#FFFFFF"
  stroke-width="2.8"
  stroke-linecap="round"
  fill="none"
  opacity="0.65"
/>
<circle cx="-9" cy="-9" r="2.2" fill="#FFFFFF" opacity="0.9" />
```

## ۵. فیزیک انیمیشن: قوانین ۱۲گانه‌ی دیزنی در وب

### ۵.۱. کشسانی و جهش کارتونی (Squash & Stretch)
هنگامی که گیاه لمس می‌شود یا عادتی تیک می‌خورد، نباید پرش ساده خطی داشته باشد. انیمیشن جهش نیازمند مراحل زیر است:
1. **پیش‌درآمد (Anticipation / Squash):** گیاه ابتدا روی محور Y جمع و روی محور X پهن می‌شود.
2. **شلیک به بالا (Stretch):** گیاه کشیده و باریک شده و با شتاب به آسمان می‌رود.
3. **لختی و پایداری (Overshoot & Settle):** عبور از نقطه‌ی تعادل و چند نوسان ژله‌ای کوچک.

منحنی Bezier انیمیشن جهش ژله‌ای:
```css
@keyframes jelly-jump {
  0%   { transform: scale(1, 1) translateY(0); }
  20%  { transform: scale(1.28, 0.72) translateY(8px); }      /* جمع شدن به زمین */
  45%  { transform: scale(0.82, 1.30) translateY(-22px) rotate(-3deg); } /* جهش کشیده */
  65%  { transform: scale(1.12, 0.92) translateY(-4px) rotate(2deg); }   /* بازگشت بیش از حد */
  80%  { transform: scale(0.96, 1.04) translateY(0); }
  100% { transform: scale(1, 1) translateY(0); }
}

.plant-happy-jump {
  animation: jelly-jump 0.85s cubic-bezier(0.28, 0.84, 0.42, 1);
}
```

### ۵.۲. تنفس ارگانیک (Organic Breathing)
نکته‌ی حیاتی: تنفس ارگانیک نباید تنها تغییر در مقیاس یکنواخت ($Scale$) باشد، بلکه باید نسبت محورهای عرض و طول معکوس شوند تا حجم ثابت بماند (Conservation of Volume):

$$\text{Volume} \approx Scale_X \times Scale_Y \approx 1.0$$

```css
@keyframes breathe-4s {
  0%, 100% { transform: scale(1) translateY(0); }
  50%      { transform: scale(1.04, 0.98) translateY(-2px); }
}

.plant-thriving {
  animation: breathe-4s 4s ease-in-out infinite;
  transform-origin: 50% 95%; /* ریشه در خاک ثابت می‌ماند */
}
```

### ۵.۳. نوسان نامتقارن برگ‌ها (Asymmetric Leaf Swaying)
برگ‌های گیاه نباید با فرکانس یکسان تاب بخورند، وگرنه کاراکتر شبیه به یک ربات به نظر می‌رسد. به برگ چپ و راست فرکانس و فاز اولیه‌ی متفاوتی اختصاص داده می‌شود:

```css
@keyframes sway-left-leaf {
  0%, 100% { transform: rotate(0deg); }
  50%      { transform: rotate(-7deg) scale(1.03); }
}
@keyframes sway-right-leaf {
  0%, 100% { transform: rotate(0deg); }
  50%      { transform: rotate(8deg) scale(1.04); }
}

.leaf-sway-l {
  animation: sway-left-leaf 3.5s ease-in-out infinite;
  transform-origin: 58px 84px; /* نقطه‌ی اتصال به ساقه */
}
.leaf-sway-r {
  animation: sway-right-leaf 3.8s ease-in-out infinite 0.4s; /* تاخیر فاز */
  transform-origin: 60px 78px;
}
```

### ۵.۴. پلک زدن طبیعی (Blink Cadence)
پلک زدن سریع رخ می‌دهد (حدود ۴٪ کل زمان یک چرخه):
```css
@keyframes eye-blink {
  0%, 94%, 100% { transform: scaleY(1); }
  96%           { transform: scaleY(0.08); } /* پلک کاملاً بسته */
}
.cartoon-eyes {
  animation: eye-blink 4.2s infinite;
  transform-origin: center;
}
```

## ۶. الگوریتم طراحی ۴ گلدان فانتزی شاخص

گلدان در جوانه صرفاً یک ظرف نیست، بلکه بخشی از هویت کودک است. ابعاد کادربندی استاندارد گلدان در کادر ۱۲۰×۱۴۰:

- سطح خاک بیضی: `cx=60, cy=95, rx=25, ry=6`
- لبه‌ی بالایی گلدان (Rim): `x=31, y=88, width=58, height=9, rx=4.5`
- بدنه‌ی مخروطی (Pot Body): `M34 95 L40 126 Q60 132 80 126 L86 95 Z`

### فرمول تمایز گلدان‌ها:
1. **سفالی خندان (Terracotta):**
   - رنگ پایه: گرادیان نارنجی رسی (`#FFAE80` به `#C7632A`).
   - ویژگی اضافه: ترسیم چشم‌های نقطه‌ای و لبخند روی دیواره‌ی گلدان در مختصات `translate(60, 112)`.
2. **توت‌فرنگی خال‌خالی (Strawberry):**
   - رنگ پایه: قرمز مرجانی تند (`#FF5964`).
   - ویژگی اضافه: دانه‌های زرد طلایی چرخانده شده حول محور گلدان با مختصات ماتریسی (`rotate(-15)` و `rotate(15)`).
3. **شیشه‌ای درخشان (Crystal Water):**
   - رنگ پایه: آبی فیروزه‌ای اقیانوسی (`#4EA8DE` به `#0077B6`).
   - ویژگی اضافه: رگه‌های بازتاب عمودی سفید با `opacity=0.65` و لوزی‌های الماس‌گون.
4. **کیهانی ستاره‌دار (Cosmic Night):**
   - رنگ پایه: بنفش فضایی عمیق (`#6A4C93` به `#442B63`).
   - ویژگی اضافه: ستاره‌های چهارپر فسفری کوچک و سحابی با ذرات زرد نئونی.

## ۷. موتور صوتی مکمل بدون فایل (WebAudio Synth Engine)

حس بصری فانتزی اگر با صدای تخت یا فایل‌های حجیم MP3 همراه شود، در شبکه‌های محلی و آفلاین شکست می‌خورد. این موتور صوتی با فرکانس‌های دقیق ریاضی صداها را روی مرورگر تولید می‌کند:

```javascript
const SfxEngine = {
  ctx: null,
  init() {
    if (!this.ctx && typeof window !== 'undefined') {
      const AudioCtx = window.AudioContext || window.webkitAudioContext;
      if (AudioCtx) this.ctx = new AudioCtx();
    }
    if (this.ctx && this.ctx.state === 'suspended') {
      this.ctx.resume().catch(() => {});
    }
  },
  
  // پخش یک تن پایه با منحنی اضمحلال ولوم
  tone(freq, delay = 0, dur = 0.18, type = 'sine', vol = 0.12) {
    try {
      this.init();
      if (!this.ctx) return;
      const now = this.ctx.currentTime + delay;
      const osc = this.ctx.createOscillator();
      const gain = this.ctx.createGain();
      
      osc.type = type;
      osc.frequency.setValueAtTime(freq, now);
      
      // انولوپ ولوم (Envelope ADSR: Attack -> Decay)
      gain.gain.setValueAtTime(0.001, now);
      gain.gain.exponentialRampToValueAtTime(vol, now + 0.02);
      gain.gain.exponentialRampToValueAtTime(0.0001, now + dur);
      
      osc.connect(gain);
      gain.connect(this.ctx.destination);
      
      osc.start(now);
      osc.stop(now + dur + 0.02);
    } catch (e) {}
  },

  // آکورد پیروزی انجام عادت (دو-می-سل ماژور C5, E5, G5)
  playHabitSuccess() {
    this.tone(523.25, 0.00, 0.16, 'sine', 0.12);
    this.tone(659.25, 0.09, 0.18, 'sine', 0.12);
    this.tone(783.99, 0.18, 0.28, 'triangle', 0.14);
  },

  // ملودی بازگشت به شادابی (سحرگاه و بیدارباش)
  playWakeUpMelody() {
    this.tone(440.00, 0.00, 0.15, 'triangle', 0.10);
    this.tone(554.37, 0.10, 0.15, 'triangle', 0.12);
    this.tone(659.25, 0.20, 0.20, 'triangle', 0.13);
    this.tone(880.00, 0.32, 0.35, 'sine', 0.15);
  }
};
```

## ۸. چک‌لیست طلایی هنگام توسعه در محیط‌های هوش مصنوعی (Google App / Vertex / LLM)

هنگامی که می‌خواهید مدل هوش مصنوعی کدی برای این کاراکتر بنویسد، این ۴ دستورالعمل را به او یادآوری کنید:
1. **قانون `transform-origin`:** همیشه برای هر انیمیشن چرخشی برگ یا سر، نقطه اتکای ساقه را مشخص کن؛ در غیر این صورت کاراکتر در فضا تکه‌تکه می‌شود.
2. **عدم استفاده از خطوط تیز:** تمام اتصالات ساقه و دهان باید دارای `stroke-linecap="round"` و `stroke-linejoin="round"` باشند.
3. **پرهیز از گرادیان یکسان برای چند کاراکتر:** هر گرادیان باید یک `id` منحصر‌به‌فرد داشته باشد تا وقتی ۲۰ گلدان کنار هم رندر می‌شوند، تداخل گرافیکی (ID Collision) رخ ندهد.
4. **رعایت دسترس‌پذیری (`prefers-reduced-motion`):** برای دانش‌آموزانی که دچار حساسیت حرکتی هستند، تمام انیمیشن‌ها در مدیاکوئری به حالت بدون حرکت برگردند.
