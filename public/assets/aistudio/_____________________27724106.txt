یک وب‌اپلیکیشن React + Tailwind بساز. اسمش «جوانه — باغچه‌ی کلاس» است. یک پنل معلم.

## ۰. زمینه (بخوان قبل از هر چیز)

«جوانه» یک بازی مراقبت از گیاه برای کودکان ۸ ساله است. هر کودک، یک گیاه دارد. گیاه، بر اساس مدت غیبت کودک، «حال» عوض می‌کند. این پنل، برای **معلم** است.

### جایگاه در ۶ لایه‌ی مالکیت
این پنل، لایه‌ی ۴ از ۶ لایه است:
1. مالک پلتفرم (`/admin`) — پنل جدا
2. مدرسه (`/school`) — پنل جدا
3. کلاس — زیرمجموعه‌ی مدرسه
4. **معلم (این پنل)** ← این را می‌سازیم
5. دانش‌آموز (PWA) — جدا
6. والدین (بله) — جدا

این پنل **فقط** برای معلم است. هیچ‌کدام از لایه‌های دیگر را نساز.

### فلسفه (نقض نکن)
- هیچ عدد، امتیاز، رتبه، لیدربورد، میانگین، یا مقایسه‌ای نباشد.
- معلم «مراقب» است، نه «کنترل‌کننده».
- گیاه باید «دعوت به مراقبت» کند، نه «ایجاد گناه».
- منبع حقیقت: **مدت واقعی غیبت** — نه امتیاز، نه عملکرد.
- گیاهان پژمرده، نشان داده می‌شوند — اما نه با رنگ قرمز، نه با متن هشدار.

### جمله‌ی راهنما
«هرچه کودک بیشتر مراقبت کند، گیاهش نه قوی‌تر، بلکه خاص‌تر و پرخاطره‌تر شود.»

## ۱. مدل داده (TypeScript)

```typescript
type Mood = 'thriving' | 'content' | 'longing' | 'alert';
type Stage = 1 | 2 | 3 | 4 | 5;

interface Plant {
  id: string;
  plantName: string;       // «جوانه»، «سبزه»، «گل»
  childName: string;       // «علی»، «مریم» — فقط در Drawer
  gen: number;             // 1, 2, 3...
  mood: Mood;
  stage: Stage;
  growthDays: number;      // 5-25
  lastSeenDays: number;    // 0-7
  activeDream: string | null;
  memoriesCount: number;   // 0-10
  archived: boolean;       // گیاه پیر
}

interface RadarData {
  overall: 'good' | 'mixed' | 'needs_care';
  overallMessage: string;  // «امروز حال باغچه متوسط است.»
  needsAttentionCount: number;
  needsAttention: Array<{
    childName: string;
    plantName: string;
    mood: 'longing' | 'alert';
    lastSeenDays: number;
    hint: string;          // پیشنهاد یک‌خطی
  }>;
  goodNews: Array<{
    type: 'comeback' | 'stage' | 'seed' | 'dream';
    text: string;
  }>;
  healthPercentage: number; // 0-100 برای نوار پیشرفت (بدون نمایش عدد)
}

interface ClassData {
  className: string;       // «کلاس سوم الف»
  totalPlants: number;
  radar: RadarData;
  plants: Plant[];
  seedBank: Plant[];       // archived plants
}
```

## ۵. RadarCard — دقیق

### محتوا
1. **جمله‌ی کلی**: بر اساس healthPercentage
   - ≥۷۰: «امروز حال باغچه خوبه.»
   - ۴۰–۶۹: «امروز حال باغچه متوسط است.»
   - <۴۰: «امروز باغچه نیاز به مراقبت داره.»

2. **نوار پیشرفت** (بدون عدد):
   - ارتفاع: ۸px
   - رنگ: gradient از #C8D9B5 به #7BA05B
   - عرض: به اندازه‌ی healthPercentage
   - انیمیشن: fill از ۰ در ۱ ثانیه

3. **خبرهای خوب** (اگر وجود دارد):
   - آیکون + متن
   - مثال: «۲ نفر بعد از چند روز برگشته‌اند.»
   - مثال: «۲ گیاه، تازه شکوفا شده‌اند.»

4. **نیاز به توجه** (اگر وجود دارد):
   - حداکثر ۳ نفر
   - هر ردیف: «[نام] — [X] روزه ندیده — پیشنهاد: [hint]»
   - hover: پس‌زمینه‌ی ملایم
   - کلیک: باز کردن Drawer همان گیاه

### حالت خالی
- اگر هیچ‌کس نیاز به توجه ندارد: «امروز، همه‌ی گیاهان حالشون خوبه.»
- اگر باغچه خالی است: «هنوز هیچ گیاهی کاشته نشده.»

## ۷. Drawer — دقیق

### باز شدن

- animation: `slide-up 0.3s ease-out`

### محتوا (به ترتیب)
1. **Header**: نام گیاه + نام کودک + نسل — با دکمه‌ی «بستن» (×)

## بخش چهارم: بعد از پیست کردن

بعد از اینکه Gemini جواب داد، **این سه چیز را بررسی کن**:

1. **آیا گیاهان حالات مختلف دارند؟** — thriving سبز روشن، alert خاکستری-سبز
2. **آیا Drawer از پایین باز می‌شود؟** — نه از راست، نه از چپ
3. **آیا در Board Mode، گیاهان longing/alert خاکستری می‌شوند؟** — نه حذف، نه قرمز

اگر هر کدام نبود، به Gemini بگو. با هم درست می‌کنیم.
